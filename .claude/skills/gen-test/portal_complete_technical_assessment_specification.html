    Automated Validation Rule: Verify cell logic utilizes native array formulas `{=TABLE()}` rather than hardcoded metrics.

Section IV: Schema Lazy-Loading & Inactive Node Pattern

To optimize platform initialization, all functions where status == "inactive" must render as valid empty arrays. The agent must format the database instantiation template exactly as follows:

{
  "database_seed": {
    "version": "1.0.0",
    "active_nodes": ["1.7"],
    "schema_template": {
      "function_id": "STRING",
      "status": "STRING",
      "assessment_payload": "ARRAY_OR_NULL"
    },
    "nodes": [
      {
        "function_id": "1.7",
        "status": "active"
      },
      {
        "function_id": "1.4",
        "status": "inactive",
        "assessment_payload": null
      }
    ]
  }
